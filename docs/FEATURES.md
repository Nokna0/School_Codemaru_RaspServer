# FEATURES — 기능 명세 (캡처 화면 기반)

근거: `reference-mirror/` 의 실제 렌더링 페이지. 각 기능의 화면,규칙을 정리한다.

## 1. 회원 / 인증
- 로그인: 아이디 + 비밀번호.
- 회원가입: 학생 인증코드 → 아이디 → 학년(1/2/3) → 반(1~11) → 비밀번호/확인 → 이용규칙,안전서약 동의.
- 안전서약 핵심(욕설/혐오/개인정보 노출/명예훼손 금지, 익명도 책임 있음) → 신고,제재 기능의 근거.

## 2. 자유게시판
- 글 목록/상세/작성, 댓글,대댓글, 추천(좋아요), 조회수.
- **익명 기능**: 작성 시 익명 선택 가능(`is_anonymous`). 표시는 "익명", 내부엔 author 보관.
- 이미지 첨부(`image_urls`).

## 3. 핫이슈 / 베스트
- 추천,댓글,조회,최신성 기반 점수(`hot_score`)로 상위 글 노출. 사이드바 "🔥 핫이슈"와 베스트 탭.

## 4. 구인구직 (jobs)
- "스터디/프로젝트/대회 팀원을 찾는 공간". 모집글 작성 + 관심분야 필터.
- 분야 카테고리(고정):
  - 과학: 물리, 화학, 생명과학, 지구과학
  - 수학/정보: 수학, 컴공, AI/데이터, 로봇
  - 인문/사회: 사회, 경제
  - 진로/기타: 의료보건, 교사/교육, 디자인, 영상, 음악, 미술, 체육
  - 활동: 대회/공모전, 스터디, 프로젝트, 봉사
- 로그인 시 "내 관심사 저장"(`/api/me/interests`) → 다음 방문에 기본 필터.

## 5. 급식 (NEIS)
- 날짜 네비게이션(이전/오늘/다음). 조식/점심/저녁 메뉴.
- 식사별 5점 별점, 평균 표시("-/5", "아직 평가 안 됨"). 1인 1식 1평점.
- 주말/방학/휴업일은 데이터 없을 수 있음(빈 상태 처리).

## 6. 시간표 (NEIS)
- 학년(1~3)×반(1~11) 선택, 주 단위(이전주/다음주). 교시(1~7)×요일(월~금) 표.
- 기본 1학년 1반. 로그인 사용자가 마이페이지에 학년/반 저장 시 자동 반영(`users.grade/class_no`).

## 7. 실시간 익명채팅
- 페이지 사이드바 상시 노출("💬 실시간 익명채팅 Live"). 텍스트 + 이모지(😀 👍 ❤️ 🔥 🚀) 전송.
- 접속자(presence) 표시(회원/방문 수). WebSocket으로 구현(`/ws`).

## 8. 등급 시스템
- `users.level`/`exp`. 활동(글/댓글/추천 받기/출석 등)으로 exp 적립 → 레벨업.
- 초기 규칙(제안): 글 +10, 댓글 +3, 추천받음 +2. 레벨 임계값 표는 단순 증가형으로 시작 후 조정.

## 9. 알림 / 쪽지
- 알림: 내 글 댓글,추천,쪽지 수신,시스템 공지. 읽음 처리.
- 쪽지: 1:1 받은편지함.

## 10. 운영 / 관리자
- 통계: 방문자 수,회원 수, 방문 분석(`/api/analytics/visit`).
- 팝업 공지, 광고 슬롯, D-day 표시.
- 관리자: 로그인 로그, 신고,보관함(소프트 삭제 글 관리), 공지/팝업/광고/코드 관리.

## 우선순위 제안
필수(MVP): 1,2,5,6,7  →  그다음: 3,4,8,9  →  마지막: 10.
(자세한 순서는 `docs/ROADMAP.md`)
